Put each quarter's original country files and Taux.xlsx in a folder such as Q4_2026 here.
No production input files are bundled. The database already contains the approved history through Q3 2026.

If your rate workbook has no date, use its actual quarter in the filename (e.g. taux_Q4_2026.xlsx) or set fx.date_override in config/countries.json after checking it.
Always update or clear a date override for the next quarter; a stale override is rejected.
